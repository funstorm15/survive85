# Content guide: writing events for survive85

Every risk in survive85 comes from the book **HowToLiveBetter** by
[eternity4719](https://github.com/eternity4719/HowToLiveBetter) (CC BY 4.0).
This guide explains how a book item becomes evidence, how evidence becomes an
event, and how to check your work. `go test ./data/` must pass before a pull
request is merged.

## 1. Files

| Path | Contents |
|---|---|
| `data/evidence/chNN.yaml` | Book items from chapter NN, quoted faithfully |
| `data/events/NN_topic.yaml` | Events built on that chapter |
| `data/conditions/NN_topic.yaml` | Lasting states (habits, illnesses, safety gear) used by those events |
| `data/professions.yaml`, `data/causes.yaml` | Starting classes, cause-of-death names |
| `data/lifetables/who2019.yaml` | Generated by `go run ./tools/genlifetables` — never edit |

Every human-readable string is bilingual: `{ru: "...", en: "..."}`. Both are
required and both must read naturally — write each language, do not
machine-translate one from the other word by word.

## 2. Evidence records

One record per book item, id `chNN_iM` (chapter zero-padded, item not), using
the item numbers of the Chinese original (they match the translations for all
items present in both).

```yaml
- id: ch01_i2
  chapter: 1
  item: 2
  chapter_title: {ru: "Как не умереть раньше времени", en: "How to avoid premature death"}
  title: {ru: "...", en: "Wearing a helmet and fastening the strap while riding motorcycles or e-bikes"}
  grade: A                 # exactly as in the book
  contested: false         # true iff the book's notes start with 争议 (controversy)
  measure: mortality       # mortality | money | time | freedom (口径 in the cost tag)
  plain: {ru: "...", en: "..."}     # the "In plain terms" line, verbatim from the translation
  benefit: {ru: "...", en: "..."}   # the "Benefit" line, verbatim
  numbers:
    - {kind: OR, value: 0.58, ci_low: 0.50, ci_high: 0.68, outcome: {ru: "смерть мотоциклиста", en: "death of a motorcyclist"}}
  sources:
    - {citation: "Liu BC et al. (2008). Helmets for preventing injury in motorcycle riders. Cochrane Database of Systematic Reviews.", url: "https://doi.org/10.1002/14651858.CD004333.pub3"}
  doi: "10.1002/14651858.CD004333.pub3"   # bare DOI of the main study, or omit
```

Rules, taken from the book's own citation policy:

* Never invent or "round" a number, DOI, URL or citation. If it is not in the
  book, it is not in the game.
* Keep the book's distinction between ratios: **OR** (比值比), **HR** (风险比),
  **RR** (相对风险), **IRR** (发病率之比). An odds ratio is not "N times the chance".
* Quotes in `plain`/`benefit` come verbatim from the community translations
  (`book/en`, `book/ru` of [dlgrv/HowToLiveBetter](https://github.com/dlgrv/HowToLiveBetter)).
  Items newer than the translation are translated faithfully from the Chinese.

## 3. Events

```yaml
- id: ch34_paracetamol_combo          # snake_case, globally unique
  title: {ru: "Простуда и температура 39°C", en: "A cold and a 39°C fever"}
  min_age: 18
  max_age: 70                          # within 18..84
  category: pharmacy                   # health chronic emergency pharmacy safety money legal work family mind travel life
  weight: 1                            # relative chance among eligible events (default 1)
  weight_by: {cardiovascular_risk: 1}  # optional: weight *= modifier^exponent (emergencies that follow risk)
  repeatable: false                    # default: offered at most once per life
  cooldown: 0                          # years before a repeatable event returns
  requires: {not_conditions: [smoker]} # optional gating, see below
  evidence: ch34_i3                    # the item the situation is about
  narrative:
    ru: |
      Вы свалились с тяжёлым ОРВИ...
    en: |
      You are down with a bad flu...
  choices:
    - id: combine
      text: {ru: "...", en: "..."}     # ≤ 90 characters, an action in the first person
      tag: risky                       # wise = what the book recommends, risky = what it warns against, neutral
      cost_money: 0                    # rubles (1 yuan ≈ 12 rubles when the book gives yuan)
      cost_will: 0                     # 0..10, willpower: discipline, effort, saying no
      cost_time: 0                     # hours spent over the year (statistics only)
      delta_health: -40
      delta_sanity: 0
      delta_wealth: 0
      stat_effects:                    # multiply hidden risk modifiers
        toxicology_liver_risk: {factor: 2.0, years: 3}   # temporary
        # oncology_risk: 1.3                             # bare number = permanent
      add_conditions: []
      remove_conditions: []
      set_flags: []
      instant_death_check:
        chance: 0.05
        scale_by: [toxicology_liver_risk]  # optional: chance *= current modifier
        cause: liver
        death_reason: {ru: "Острая печёночная недостаточность...", en: "Acute liver failure..."}
        evidence: ch34_i3
      outcome: {ru: "...", en: "..."}  # what happened (1–2 sentences), shown with the evidence card
      evidence: ch34_i3
      death_reasons:                   # optional: how a later death from this cause is described
        liver: {ru: "Цирроз печени после...", en: "Liver cirrhosis after..."}
```

Requirements (`requires` on events and choices): `flags`, `not_flags`,
`flag_years: {flag: years_since_set}`, `conditions`, `not_conditions`,
`min_wealth`, `max_wealth`, `min_health`, `max_health`, `min_sanity`,
`max_sanity`, `min_risk: {risk: value}`, `classes: [profession ids]`,
`sex: male|female`. A choice whose requirements fail is hidden; one the
player cannot afford (money, will) is shown disabled.

A catastrophe (`catastrophe_check`) is a severe non-fatal outcome:
`{chance, scale_by, kind: prison|injury|ruin, years (prison term),
wealth_fraction, delta_health, delta_sanity, delta_wealth, add_conditions,
text, evidence}`.

### Hidden risk modifiers

| Key | Scales (WHO cause group) |
|---|---|
| `cardiovascular_risk` | cardiovascular disease + diabetes |
| `oncology_risk` | malignant neoplasms |
| `toxicology_liver_risk` | digestive & liver disease, alcohol/drug disorders, poisonings |
| `trauma_accident_risk` | injuries except poisonings and self-harm |
| `legal_prison_risk` | yearly arrest chance = 1.2% × (modifier − 1); catastrophe checks via `scale_by` |

Self-harm follows Sanity; everything except injuries follows Health.

### Turning a book number into a factor

The annual check multiplies each cause's **hazard** by its modifier, which is
exactly how a hazard ratio acts. So:

1. **HR/RR on the matching outcome** → use it directly: smoking-related lung
   cancer is most of the smoking effect on `oncology_risk`, a statin's HR on
   cardiovascular death goes on `cardiovascular_risk`.
2. **Outcome narrower than the game's cause group** → dilute by the share `s`
   of that group the outcome represents: `factor = 1 − s × (1 − HR)`.
   Example: potassium salt, stroke RR 0.86, strokes ≈ 40% of cardiovascular
   deaths → `1 − 0.4 × 0.14 ≈ 0.94`. Write the arithmetic in a YAML comment.
3. **OR** → treat as RR only when the book says the outcome is rare.
4. **Effects that only matter in a situation** (a helmet in a crash, a smoke
   alarm in a fire) → put the situation in the event and use an
   `instant_death_check` whose chance keeps the book's ratio between the
   protected and unprotected choices. The absolute chance is a game
   approximation (keep it ≤ 0.15 and say so in a comment); the ratio is data.
5. **Money and freedom items** (guarantees, microloans, scams, illegal work)
   → `delta_wealth`, `catastrophe_check` and `legal_prison_risk`, sized by the
   amounts and penalties the book quotes.
6. Habits that last (smoking, drinking, sitting, controlled blood pressure)
   are **conditions** with `modifiers`; a later event can remove them
   (quitting) and add an ex-state with smaller modifiers.

Factors multiply, but real risk factors overlap, so the product is corrected
beyond ×2 (and below ×0.5): the excess grows as a 0.6 power, then the result
is clamped to [0.25, 25]. A single factor must lie in (0, 10].

The life table describes the *average* person, smokers and heavy drinkers
included. A refusal of a common risk (never starting to smoke) may therefore
carry a protective factor equal to 1 / (population-average modifier) — show
that calculation too (see `ch02_first_cigarette`).

## 4. Writing

* Second person, present tense, 2–4 sentences, concrete and a little grim — a
  roguelike, not a leaflet. No lectures in the narrative: the evidence card
  after the choice teaches.
* Universal settings. The book often uses Chinese law as the example; keep the
  risk, drop the jurisdiction (no PRC phone numbers or article numbers in
  narratives). The Russian text may use Russian realities (МФО, скорая 103/112),
  the English text neutral ones (112/911).
* Do not leak the answer in the choice text ("the safe option…"). Make the
  risky choice tempting: cheaper, faster, more fun, socially easier.
* Each choice that changes a risk or has a check must carry `evidence`.
* Tags: `wise` only when the book recommends it; `risky` only when it warns.

## 5. Checking

```sh
go test ./data/                 # schema, translations, references
go run ./cmd/survive85 validate # counts
go run ./cmd/survive85 sim      # careful vs random vs reckless survival
```
