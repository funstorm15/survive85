Вам 18. Один ход — один год жизни. Каждый год — одна ситуация: друг
«выпил всего пару пива» и зовёт в машину, рядом с «Терафлю» лежит пачка
парацетамола, приятель просит стать поручителем по кредиту, начальник орёт
на вас при всём отделе. И два-четыре варианта, как поступить.

Под капотом актуарный движок умножает **реальную вероятность умереть по
данным ВОЗ для вашего возраста, пола и страны** на **отношения рисков ваших
решений** из книги
[**HowToLiveBetter**](https://github.com/eternity4719/HowToLiveBetter)
(772 рекомендации с уровнями доказательности A/B/C, мета-анализы, когорты,
РКИ). После смерти вы получаете **протокол вскрытия**: причину, решение,
которое к ней привело, исследование с DOI и сколько лет жизни потеряно.

Доживёте до 85 — победа. Российские мужчины доживают в 15,7% случаев. Удачи.

## Возможности

- **Настоящее актуарное ядро.** Таблицы смертности ВОЗ (2019) для мира,
  России и США по полу, пересчитанные на каждый год жизни и разбитые на шесть
  групп причин по Global Health Estimates ВОЗ. Модификаторы умножают
  *интенсивность* смертности от каждой причины — ровно так работает отношение
  рисков (HR).
- **106 событий, 234 варианта, 116 пунктов книги** из 20 глав: дороги и
  пожары, курение и соль, неотложные ситуации, домашняя аптечка, кредиты и
  поручительства, «красные линии» айтишников, производственные травмы, горе,
  внешность, отношения, поездки.
- **Карточка доказательств после каждого решения**: глава, пункт, уровень
  A/B/C, объяснение простыми словами, HR/OR/RR с доверительными интервалами,
  источник, DOI и ссылка на пункт книги.
- **Протокол вскрытия**: решающее решение, потерянные годы жизни по таблице,
  сколько ровесников вы пережили, вскрытые скрытые модификаторы.
- **Два языка**: русский и английский, переключение на лету клавишей `L`.
  Язык определяется по `$LANG`.
- **Шесть профессий**, три темы (Nord, Cyberpunk, Monokai), сила воли как
  ресурс, состояния на годы, цепочки событий (поручились в 25 — банк пришёл
  в 27), тюремные сроки, долговые спирали.
- **Воспроизводимые жизни**: `-seed N` или `-daily` (сегодня у всех одна и та
  же жизнь). Кладбище хранит прошлые забеги.
- **Vim-клавиши**, стрелки, цифры; помещается в терминал 80×24.
- **Один статический бинарник** без зависимостей: Arch, Kali, Parrot, Ubuntu,
  Alpine, Raspberry Pi (armv7/arm64), macOS.

## Установка

**Одной строкой (Linux, macOS)** — скачает релиз, проверит SHA-256 и
поставит в `~/.local/bin`:

```sh
curl -fsSL https://raw.githubusercontent.com/funstorm15/survive85/main/scripts/install.sh | sh
```

**Arch Linux (AUR)**:

```sh
yay -S survive85        # сборка из исходников
yay -S survive85-bin    # готовый бинарник
```

**Go**:

```sh
go install github.com/funstorm15/survive85/cmd/survive85@latest
```

**Debian / Ubuntu / Kali / Parrot, Fedora, Alpine**: пакеты `.deb`, `.rpm` и
`.apk` прикреплены к каждому [релизу](https://github.com/funstorm15/survive85/releases).

**Из исходников**:

```sh
git clone https://github.com/funstorm15/survive85 && cd survive85
make build && ./survive85
```

## Игра

```sh
survive85                 # язык из $LANG
survive85 -lang en        # in English
survive85 -seed 42        # воспроизводимая жизнь
survive85 -daily          # общая жизнь дня
survive85 -theme cyberpunk
```

| Клавиша | Действие |
|---|---|
| `↑` `↓` / `k` `j` | выбор |
| `Enter` `Space` `l` | решить / подтвердить |
| `h` `Esc` | назад |
| `1`–`4` | быстрый выбор варианта |
| `PgUp` `PgDn` | прокрутка длинных экранов |
| `L` | русский ⇄ английский |
| `T` | сменить тему |
| `?` | помощь |
| `q` `Ctrl+C` | выход |
| `r` (после смерти) | прожить ту же судьбу заново |

**Характеристики.** *Здоровье* (0–100) меняет смертность от болезней
относительно типичного для вашего возраста; на нуле — смерть. *Психика*
(0–100) определяет риск суицида; при низкой открываются кризисные события.
*Капитал* покупает мудрые решения; долг стоит 20% в год. *Сила воли*
(◆, 0–10) тратится на дисциплинированные решения и восстанавливается каждый
год. *Скрытые модификаторы* — сердце и сосуды, онкология, печень и токсины,
травмы, закон — открываются только в протоколе вскрытия.

## Как считается смертность

Каждый год в возрасте *a*:

1. Берётся вероятность *q(a)* из таблицы ВОЗ для страны и пола и переводится
   в интенсивность смертности *μ = −ln(1 − q)*.
2. *μ* делится на шесть групп причин по долям ВОЗ для вашей возрастной
   группы: сердце и сосуды, онкология, печень и отравления, травмы, суицид,
   прочее.
3. Интенсивность каждой причины умножается на ваш модификатор (произведение
   всех активных факторов и состояний с поправкой на перекрытие выше ×2 и
   ограничением [0,25; 25]). Болезни дополнительно масштабируются здоровьем
   относительно типичного для возраста, суицид — психикой.
4. Вы умираете с вероятностью *1 − exp(−Σ скорректированных интенсивностей)*;
   причина выбирается пропорционально им.

При всех модификаторах, равных 1, игра в точности воспроизводит таблицу ВОЗ
(это покрыто тестами). Как цифры книги превращаются в коэффициенты, описано в
[docs/CONTENT_GUIDE.md](docs/CONTENT_GUIDE.md): HR для того же исхода
используется напрямую, HR для более узкого исхода разбавляется его долей в
группе причин (расчёт записан комментарием в YAML рядом с каждым
коэффициентом), а эффекты конкретной ситуации (шлем в аварии) становятся
мгновенными проверками, которые сохраняют соотношение из книги. Абсолютные
шансы мгновенных проверок помечены как игровые приближения.

## Структура проекта

```
cmd/survive85/        точка входа: play, sim, validate, version
internal/actuary/     таблицы смертности: q(x), e(x), доли причин
internal/events/      модель данных, загрузка и проверка YAML, выбор событий
internal/game/        состояние игрока, калькулятор рисков, движок по годам
internal/sim/         безголовый Монте-Карло симулятор баланса
internal/i18n/        тексты ru/en, определение локали, деньги
internal/tui/         Bubble Tea, экраны, темы Lip Gloss, компоненты
data/                 встроенные YAML: события, доказательства, состояния, таблицы
tools/genlifetables/  пересобирает таблицы смертности из API ВОЗ
tools/validatedata/   проверяет данные (можно по одной главе)
scripts/              install.sh, PKGBUILD, PKGBUILD-bin
```

`make help` покажет все задачи: `build`, `test`, `lint`, `validate`, `sim`,
`lifetables`, `snapshot`, `aur`, `install`.
